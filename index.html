Builder repository

Use this repo or a separate private repo containing the included workflow.

Recommended token permissions on the builder repo: Contents: read/write and Actions: read/write. The token is never written into the project or APK.
Privacy: browser uploads are committed temporarily to the builder repo. Deleting them after a build does not erase Git history, so use a private builder repository for private/proprietary source.

What “complete offline APK” means here

Works well

Standalone HTML tools, games, dashboards, local AI/model demos, PWAs, React/Vue/Svelte builds, bundled media, fonts, WASM and static data.

Needs app-specific work

Apps that call cloud APIs, require login servers, stream data, use remote databases, or depend on a website backend.

Not a generic conversion

Windows EXEs, macOS apps, arbitrary desktop binaries, iOS apps, or native software compiled for another CPU/OS cannot simply be wrapped into Android.
